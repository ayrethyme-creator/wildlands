# Species cut from the new game

**This file does not touch Safari Saga.** Nothing here is deleted from `main` —
these are entries that simply do not travel to the new roster. The old game
keeps everything it has.

Cuts are recorded as a list rather than applied to any `game.part*.jsx`, because
the new game will be built fresh in Godot and this is the roster it starts from.

---

## Approved cuts — Ayr, 2026-08-25

### Rainforest (10) — 91 → 81

| Cut | Reason |
|---|---|
| **Harpy Eyas** `harpyeagle_e` | Not a species. A life stage of the harpy eagle |
| **Margay** `margay` | Ocelot is in the same biome and near-identical |
| **Marbled Cat** `marbledcat` | Clouded leopard is here — same pattern, same niche |
| **Kodkod** `kodkod` | Rusty-spotted cat has the better hook: world's smallest cat |
| **Siamang** `siamang` | It *is* a gibbon, and gibbon is already on the list |
| **Spectacled Flying Fox** `spectacledflyingfox` | Fruit Bat is here and is effectively the same animal |
| **Military Macaw** `militarymacaw` | Scarlet and Hyacinth are here; three macaws is one too many |
| **Hercules Beetle** `herculesbeetle` | Goliath Beetle is here — both are "enormous beetle" |
| **Silky Anteater** `silkyanteater` | Tamandua is here, Giant Anteater is in savanna |
| **Common Treeshrew** `commontreeshrew` | Not a primate, not distinctive, no hook |
