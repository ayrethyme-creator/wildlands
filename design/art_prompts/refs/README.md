# Reference images Ayr supplied, 2026-09-11

Sheet one of the myth review. Ayr: "the descriptions i made are minor fixes.
the ones that are pictures need to be redone from scratch to look more like
the picture."

That is a distinction worth keeping. A note is a correction to a drawing that
is basically right; a picture means the drawing was aimed at the wrong animal
and the prompt has to be rebuilt around what the creature actually looks like
in its own tradition.
